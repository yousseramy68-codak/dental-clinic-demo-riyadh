# Dental Clinic Demo — Riyadh

A concept preview of a multi-page, bilingual (Arabic RTL / English) website for a dental and cosmetic clinic.

## Features
- 5 pages: Home, Services, About, Booking, Contact
- Dark/light theme with an animated sliding switch
- Hero video: separate sources for desktop and mobile
- Arabic/English toggle with full RTL support
- Booking form that opens WhatsApp with a prefilled message
- Live open/closed status based on clinic hours (Asia/Riyadh)
- Self-hosted fonts and icons (IBM Plex Sans Arabic, Material Symbols)
- No frameworks, no build step

## Run locally
Open `index.html`, or run `python3 -m http.server`.
